# Requisitos Funcionales

RF-01: El sistema debe permitir que un usuario registrado inicie sesión mediante correo electrónico y contraseña válidos.

RF-02: El sistema debe permitir consultar el listado de productos disponibles.

RF-03: El sistema debe permitir consultar el detalle de un producto en específico.

RF-04: El sistema debe permitir registrar nuevos productos al catálogo.

RF-05: El sistema debe permitir modificar la información de los productos.

RF-06: El sistema debe permitir eliminar productos que ya no se comercialicen.

RF-07: El sistema debe permitir relacionar una o varias categorías existentes a un producto.

RF-08: El sistema debe permitir registrar categorías de productos.

RF-09: El sistema debe permitir modificar la información de las categorías.

RF-10: El sistema debe permitir consultar las categorías disponibles.
