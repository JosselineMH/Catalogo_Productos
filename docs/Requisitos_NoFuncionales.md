# Requisitos No Funcionales

## RNF-01: Validación de datos

El sistema debe validar los datos requeridos antes de registrar o modificar productos y categorías.

## RNF-02: Manejo de errores

El sistema debe manejar los errores de forma controlada y retornar respuestas claras desde la API, permitiendo identificar a que corresponde el problema.

## RNF-03: Mantenibilidad

El sistema debe organizarse bajo una estructura modular que separe responsabilidades entre rutas, controladores, servicios, entidades y acceso a datos.

## RNF-04: Usabilidad

El sistema debe proporcionar una interfaz sencilla e intuitiva que permita consultar, registrar, modificar y eliminar productos o categorías.

## RNF-05: Seguridad

El sistema debe proteger el acceso mediante autenticación de usuarios registrados.
